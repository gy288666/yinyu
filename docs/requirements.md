# 音域 YINYU 在线音乐平台 — 需求文档

- 版本：v1.0
- 日期：2026-07-26
- 状态：评审稿

---

## 1. 项目概述

### 1.1 项目定位

音域 YINYU 是一个自建曲库的在线音乐平台，包含两个前端工程与一个后端服务：

| 端 | 技术 | 说明 |
| --- | --- | --- |
| 用户门户（portal） | React 18，暗色金色主题 | 面向游客与注册用户的听歌门户，含全局底部播放器 |
| 管理后台（admin） | React 18 + Ant Design | 面向运营/管理员的内容管理与数据看板 |
| 后端服务 | Spring Boot 3 + Java 17 + MyBatis-Plus | 统一 REST API，前缀 `/api` |

依赖中间件：

| 组件 | 用途 |
| --- | --- |
| MySQL 8 | 业务数据持久化 |
| Redis | 播放量计数、排行榜 ZSet、验证码/Token 黑名单、热搜词 |
| MinIO | 音频文件（`music` 桶）、封面/歌手图片（`image` 桶）对象存储 |

### 1.2 素材说明

- 音频素材为一批**合规纯音乐**，开发期位于开发者本机 `E:\yinyu-music\resource\static\music`，通过后台"音乐管理"上传，落地到 MinIO `music` 桶。
- 歌手图片位于仓库 `resource/static/img/singer`，上传后存 MinIO。
- 播放/下载一律通过后端签发的 **MinIO 预签名 URL**，不暴露桶的公开读权限。

### 1.3 范围声明

- 本期实现：内容管理全链路（上传→审核→上架→播放）、门户浏览与播放、喜欢/收藏/评论、会员购买（支付宝沙箱或模拟支付）、RBAC 后台。
- 本期不实现：真实版权采买流程、移动端 App、社交关注/私信、真实唱片公司结算。

## 2. 用户角色

| 角色 | 获取方式 | 能力边界 |
| --- | --- | --- |
| 游客 | 无需登录 | 浏览发现页/歌单/歌手/排行榜，试听普通曲目（可限制码率或试听时长，见 FR-12.6）；不能喜欢、收藏、评论、下载、购买 |
| 注册用户 | 门户注册 | 游客全部能力 + 完整播放普通曲目、喜欢/收藏、评论、自建歌单、最近播放、私人FM、购买单曲、开通会员 |
| VIP 会员 | 付费开通（按月/季/年） | 注册用户全部能力 + 播放/下载 VIP 曲目、Hi-Res 专区无损音质、下载配额提升、专属标识 |
| 管理员 | 超级管理员在后台创建 | 按角色授予的菜单/按钮权限操作后台（如内容运营只管音乐/歌单，审核员只管审核） |
| 超级管理员 | 系统内置账号（admin） | 后台全部权限，含管理员/角色/权限管理、系统设置；不可被删除或停用 |

权限模型：后台采用 RBAC（用户-角色-权限三表 + 关联表），权限粒度到"菜单 + 按钮/接口"；门户用户与后台管理员是**两套独立账号体系、两套登录接口、两套 JWT**（token 中携带 `userType` 区分，见 api.md 全局约定）。

## 3. 功能需求

> 编号规则：FR-模块.条目。每条含「描述」与「验收要点」。验收要点是可直接转成测试用例的判定条件。

### FR-1 认证与账户

- **FR-1.1 用户注册**
  描述：门户以用户名 + 密码 + 昵称注册（邮箱/手机号选填），密码 BCrypt 存储。
  验收：用户名唯一冲突返回业务码 `10002`；密码明文不落库、不出现在任何日志；注册成功自动登录并返回 token 对。
- **FR-1.2 用户登录/登出**
  描述：用户名密码登录，签发 accessToken（2h）+ refreshToken（7d）；登出将 accessToken 加入 Redis 黑名单直至过期。
  验收：密码错误 5 次后锁定 10 分钟（Redis 计数）；登出后携带旧 token 访问受保护接口返回 401。
- **FR-1.3 Token 刷新**
  描述：`refreshToken` 换取新 token 对，旧 refreshToken 作废（rotation）。
  验收：同一 refreshToken 第二次使用返回 401；刷新不要求 accessToken 有效。
- **FR-1.4 管理员登录**
  描述：后台独立登录接口，支持图形验证码（Redis 存 5 分钟）；登录成功返回 token + 权限标识列表 + 菜单树。
  验收：门户用户 token 访问后台接口返回 403；被停用管理员登录返回 `10005`。
- **FR-1.5 个人资料**
  描述：用户可查看/修改昵称、头像、性别、签名，修改密码需验证旧密码。
  验收：头像上传走 MinIO 并返回可访问 URL；改密后旧 token 全部失效。

### FR-2 音乐管理（后台）

- **FR-2.1 音乐上传**
  描述：管理员上传音频文件（mp3/flac/wav，≤200MB），后端解析时长、码率，存 MinIO `music` 桶（key：`{songId}.{ext}`），并填写歌名、歌手、专辑、分类、歌词（LRC 文本）、封面、是否 VIP、单曲价格。
  验收：非白名单格式返回 `20001`；上传成功后曲目状态为「待审核」，门户不可见；MinIO 中可查到对象且 DB 记录 objectKey。
- **FR-2.2 音乐列表/检索**
  描述：分页列表，支持按歌名/歌手/专辑/分类/状态（待审核/已上架/已驳回/已下架）筛选。
  验收：分页参数越界返回空列表而非报错；筛选组合可叠加。
- **FR-2.3 音乐编辑/上下架/删除**
  描述：可编辑元数据、手动下架/重新上架、逻辑删除（`deleted` 标记）。
  验收：下架曲目门户列表不出现且播放地址接口返回 `20003`；删除不物理删除 MinIO 对象（保留 30 天由清理任务处理）。
- **FR-2.4 批量导入**
  描述：支持一次多选文件上传，按文件名预填歌名，逐条落库为待审核。
  验收：单个文件失败不影响其余文件，返回逐条结果清单。

### FR-3 音乐审核（后台）

- **FR-3.1 待审核列表**
  描述：独立审核工作台，Tab 分「待审核/已通过/已驳回」，可在线试听待审核曲目。
  验收：审核员角色仅见审核菜单也能试听（试听 URL 不要求曲目已上架）。
- **FR-3.2 审核通过**
  描述：通过后曲目状态置「已上架」，门户立即可见，记录审核人与时间。
  验收：通过操作写入操作日志；门户新歌速递中出现该曲目。
- **FR-3.3 审核驳回**
  描述：驳回必须填写原因（≥5 字），状态置「已驳回」。
  验收：无原因提交被拦截；驳回原因在音乐管理列表可见。
- **FR-3.4 批量审核**
  描述：支持勾选多条批量通过/驳回（驳回共用一个原因）。
  验收：批量结果返回成功/失败条数。

### FR-4 歌手管理

- **FR-4.1 歌手 CRUD（后台）**
  描述：维护歌手名、头像（来源 `resource/static/img/singer`，上传至 MinIO）、地区、类型（男/女/组合/纯音乐厂牌）、简介。
  验收：删除被歌曲引用的歌手时拦截并提示 `20005`；头像缺省时使用占位图。
- **FR-4.2 歌手门户页**
  描述：门户歌手列表（按地区/类型/首字母筛选）与详情页（简介 + 歌曲列表 + 专辑列表）。
  验收：详情页歌曲仅含「已上架」；游客可浏览。

### FR-5 专辑管理

- **FR-5.1 专辑 CRUD（后台）**
  描述：专辑名、封面、所属歌手、发行日期、简介，并可在专辑内维护曲目顺序。
  验收：专辑曲目排序保存后门户详情页按序展示。
- **FR-5.2 专辑门户页**
  描述：专辑详情含封面、简介、曲目列表，可整专辑加入播放队列、收藏专辑。
  验收：收藏后出现在"我的收藏-专辑"。

### FR-6 歌单

- **FR-6.1 官方歌单管理（后台）**
  描述：运营创建官方歌单（标题、封面、标签、简介、曲目及顺序），支持置顶/推荐位标记。
  验收：标记"推荐"的歌单进入门户"热门歌单"候选。
- **FR-6.2 歌单广场（门户）**
  描述：按标签/分类筛选歌单，卡片展示封面、标题、播放量。
  验收：播放量取 Redis 累计值；点击卡片进详情。
- **FR-6.3 歌单详情**
  描述：展示曲目列表（序号、歌名、歌手、时长、VIP 标）、播放全部、收藏、分享链接。
  验收：VIP 曲目对非会员点击播放时按 FR-12.6 拦截。
- **FR-6.4 用户自建歌单**
  描述：注册用户创建/编辑/删除私人歌单，支持从任意曲目列表"添加到歌单"，可设为公开/私密。
  验收：私密歌单他人通过 URL 访问返回 `20006`；同一曲目重复添加去重。

### FR-7 分类管理

- **FR-7.1 分类 CRUD（后台）**
  描述：两级分类（如"场景→学习/助眠"、"风格→钢琴/电子"），控制启用状态与排序。
  验收：停用分类不在门户筛选项出现；被引用分类删除时拦截。

### FR-8 版权管理（后台）

- **FR-8.1 版权信息维护**
  描述：为曲目登记版权方、授权类型（买断/分成/CC 协议）、授权起止日期、授权文件（MinIO 存储）。
  验收：授权到期前 7 天在后台看板"实时动态"产生提醒；到期曲目自动下架（每日定时任务）。

### FR-9 门户发现页

- **FR-9.1 轮播横幅**
  描述：顶部轮播图（后台配置图片、跳转链接、顺序、起止时间）。
  验收：仅展示在有效期内且启用的图；无有效图时区域隐藏。
- **FR-9.2 每日推荐**
  描述：每天 0 点生成 30 首推荐（策略：用户喜欢的分类加权 + 热门补足；游客用全站热门），Redis 缓存 24h。
  验收：同一用户当日两次访问结果一致；次日更新。
- **FR-9.3 楼层区块**
  描述：发现页依次为：轮播、每日推荐、歌单广场入口、排行榜入口、电台入口、Hi-Res 专区入口、为你推荐、热门歌单、新歌速递。
  验收：各楼层数据接口独立，单个接口失败不阻塞整页（前端骨架屏降级）。
- **FR-9.4 Hi-Res 专区**
  描述：聚合 flac/wav 无损曲目，仅 VIP 可完整播放。
  验收：非 VIP 点击播放弹开通引导。

### FR-10 排行榜

- **FR-10.1 四大榜单**
  描述：热歌榜（近 7 天播放量）、新歌榜（近 30 天新上架按播放量）、原创榜（标记原创的曲目）、飙升榜（今日播放量/昨日播放量 增幅）。
  验收：榜单数据来自 Redis ZSet，每小时快照落 MySQL；榜单页展示排名变化（升/降/新）。
- **FR-10.2 榜单页交互**
  描述：榜单前 3 名大图展示，支持"播放全部"。
  验收：播放全部按榜单顺序入队。

### FR-11 搜索

- **FR-11.1 综合搜索**
  描述：按关键字搜歌曲/歌手/专辑（Tab 切换），MySQL `LIKE` + 相关度排序（歌名精确 > 前缀 > 包含）。
  验收：空关键字返回 `10001`；仅返回已上架曲目。
- **FR-11.2 热搜与联想**
  描述：热搜词取 Redis ZSet（搜索行为计数），输入联想返回前 10 条歌名/歌手名。
  验收：联想接口 P95 < 200ms。

### FR-12 播放器与播放

- **FR-12.1 全局底部播放器**
  描述：门户所有页面共享底部播放器：封面、歌名/歌手、播放/暂停、上一首/下一首、进度条（可拖动）、音量、播放模式（顺序/单曲循环/随机）、播放队列面板、喜欢按钮。
  验收：路由切换不中断播放；刷新页面恢复队列与进度（localStorage）。
- **FR-12.2 播放地址获取**
  描述：播放前调用 `GET /api/songs/{id}/url` 获取 MinIO 预签名 URL（有效期 30 分钟），同一次调用完成播放量埋点。
  验收：预签名 URL 过期后直接访问 MinIO 返回 403；接口对下架曲目返回 `20003`。
- **FR-12.3 播放量计数（Redis）**
  描述：埋点写 Redis：`INCR song:play:total:{id}`、`ZINCRBY rank:day:{yyyyMMdd}`，每 5 分钟定时任务合并回写 MySQL 总量字段。
  验收：播放接口不直接写 MySQL；同一用户同一曲目 30 秒内重复请求只计 1 次（Redis SETNX 去重）。
- **FR-12.4 HTTP Range 支持**
  描述：音频经 MinIO 直连播放，MinIO 原生支持 Range；若走后端代理流（备选方案），后端必须实现 `Range/Content-Range/206`。
  验收：拖动进度条到任意位置 1s 内出声；`curl -H "Range: bytes=100-200"` 返回 206 且 body 101 字节。
- **FR-12.5 歌词**
  描述：播放页支持 LRC 歌词滚动高亮（纯音乐无词时显示"纯音乐，请欣赏"）。
  验收：歌词时间轴与进度同步误差 < 500ms。
- **FR-12.6 权益拦截**
  描述：VIP 曲目：游客/普通用户请求播放地址返回 `30001`（前端弹开通引导）；单曲付费曲目未购买返回 `30002`；游客播放普通曲目限制试听 60 秒（前端按 `trialSeconds` 字段截断）。
  验收：拦截发生在后端 URL 签发环节，绕过前端直接调接口同样被拦。

### FR-13 推荐 / 私人FM / 电台

- **FR-13.1 为你推荐**
  描述：基于用户喜欢/收藏的分类与歌手做加权随机，冷启动用热门兜底。
  验收：登录用户与游客返回内容不同；每次刷新有变化。
- **FR-13.2 私人FM**
  描述：一键连续播放模式，每次取 1 首下一曲（不喜欢可标记，7 天内不再出现）。
  验收：标记"不喜欢"后连续拉取 20 次不出现该曲；FM 模式下播放器隐藏上一首。
- **FR-13.3 电台**
  描述：运营配置主题电台（本质是循环随机播放的歌单，如"助眠"、"咖啡馆"）。
  验收：电台页可直接播放，曲目随机不重复直至遍历完一轮。

### FR-14 喜欢 / 收藏 / 最近播放 / 下载

- **FR-14.1 喜欢歌曲**
  描述：红心切换，落库并计入"我喜欢的音乐"（系统内置歌单，不可删除）。
  验收：重复喜欢幂等；取消后立即从列表消失。
- **FR-14.2 收藏歌单/专辑**
  描述：收藏他人公开歌单、官方歌单、专辑，入口在详情页。
  验收：收藏数实时 +1；被收藏歌单转私密后收藏列表标记"已失效"。
- **FR-14.3 最近播放**
  描述：服务端记录最近 200 条播放（去重保序，最新在前），可清空。
  验收：同一曲目再次播放时移到首位而非重复插入。
- **FR-14.4 下载管理**
  描述：注册用户可下载普通曲目（每日 10 首），VIP 下载 VIP 曲目且配额 100 首/日；下载走预签名 URL（`response-content-disposition=attachment`）；门户提供下载记录页。
  验收：超配额返回 `30003`；下载记录含文件大小与时间。

### FR-15 评论

- **FR-15.1 发表/删除评论**
  描述：注册用户对歌曲、歌单发表评论（≤500 字），支持一层回复；本人与管理员可删除。
  验收：包含敏感词（词库表配置）的评论提交返回 `40001`；删除父评论时子回复级联标记删除。
- **FR-15.2 评论点赞与排序**
  描述：评论可点赞，列表支持"最热/最新"两种排序。
  验收：点赞幂等；最热按点赞数倒序。

### FR-16 会员与支付

- **FR-16.1 会员套餐**
  描述：套餐（月/季/年）由后台配置价格与时长，门户会员中心展示权益对比。
  验收：改价后新订单用新价，已支付订单不受影响。
- **FR-16.2 创建订单**
  描述：用户选套餐或单曲生成订单（编号规则 `yyyyMMddHHmmss+6位随机`），15 分钟未支付自动关闭（Redis 过期事件或定时扫描）。
  验收：重复点击不产生重复待支付订单（同用户同商品存在待支付订单时直接返回原订单）。
- **FR-16.3 支付（支付宝沙箱 / 模拟）**
  描述：优先接支付宝沙箱（PC 网页支付 + 异步 notify 回调验签）；无沙箱环境时启用模拟支付开关（系统设置项 `pay.mock=true`），点击"模拟支付成功"直接回调。
  验收：notify 验签失败不改订单状态并记日志；支付成功后订单置「已支付」且立即生效（VIP 到期时间累加 / 单曲购买记录生成），回调幂等（重复 notify 不重复加时长）。
- **FR-16.4 订单查询**
  描述：门户"我的订单"分页展示，状态：待支付/已支付/已关闭/已退款（退款仅后台手工标记）。
  验收：待支付订单展示剩余支付倒计时。
- **FR-16.5 单曲购买**
  描述：付费单曲（后台定价）购买后永久播放/下载权。
  验收：已购曲目播放地址接口不再返回 `30002`；重复购买被拦截。

### FR-17 用户运营（后台）

- **FR-17.1 用户列表**
  描述：分页检索（用户名/昵称/状态/是否 VIP），可查看详情（资料、VIP 到期、最近登录）、启用/停用、重置密码。
  验收：停用用户下次请求任意受保护接口返回 401 且提示被停用；重置密码生成随机密码并要求首次登录修改。
- **FR-17.2 会员管理**
  描述：查看 VIP 用户列表与到期时间，支持手工赠送/调整 VIP 时长（记操作日志）。
  验收：调整后门户会员中心到期时间即时变化。
- **FR-17.3 用户等级**
  描述：按累计播放时长升级（Lv1-Lv10，阈值后台可配），等级在门户个人页与评论区展示。
  验收：阈值修改后每日任务重算等级。
- **FR-17.4 用户反馈**
  描述：门户提交反馈（类型 + 内容 + 可选截图），后台列表处理（回复/关闭），用户可见回复。
  验收：状态流转：待处理→已回复→已关闭；后台回复后用户反馈页显示回复内容。

### FR-18 运营内容（后台配置 + 门户展示）

- **FR-18.1 轮播图管理**
  描述：图片（MinIO）、标题、跳转类型（歌单/专辑/活动/外链）、排序、起止时间、启用开关。
  验收：门户接口只返回 `enabled=1` 且当前时间在有效期内的记录，按 sort 升序。
- **FR-18.2 公告管理**
  描述：后台发布/撤回公告（标题、富文本、生效时间），门户顶部与看板展示最新公告。
  验收：撤回后门户不再展示；看板"系统公告"取最新 5 条。
- **FR-18.3 活动管理**
  描述：运营活动（标题、封面、详情富文本、起止时间、上线/下线），门户活动页与轮播可跳转。
  验收：过期活动自动标记"已结束"仍可查看详情。

### FR-19 数据看板与统计（后台）

- **FR-19.1 看板核心指标**
  描述：音乐总数、用户总数、今日播放量（Redis 当日 key）、付费会员数、累计收益（已支付订单求和），每项带较昨日环比。
  验收：今日播放量与 Redis 值一致；接口聚合一次返回，P95 < 1s（收益等慢查询缓存 5 分钟）。
- **FR-19.2 播放量趋势折线图**
  描述：近 7/30 天每日播放量折线（数据来自每日快照表）。
  验收：切换 7/30 天粒度正确；当日数据为实时 Redis 值。
- **FR-19.3 用户来源渠道环形图**
  描述：注册时记录渠道（direct/search/share/activity），环形图展示占比。
  验收：占比合计 100%；无数据时展示空态。
- **FR-19.4 实时动态 / 热门 TOP5 / 快捷操作**
  描述：实时动态流（最新注册、最新订单、审核事件、版权到期提醒，取最近 20 条）；热门歌曲 TOP5（今日播放 ZSet）；快捷操作卡片（上传音乐/发公告/加轮播/审核入口）。
  验收：快捷操作按当前管理员权限过滤（无审核权限不显示审核入口）。
- **FR-19.5 数据统计页**
  描述：独立统计页：播放量、注册量、订单收益按日/周/月聚合查询与导出 CSV。
  验收：导出文件与页面数据一致；时间范围最大 1 年。

### FR-20 RBAC 权限体系（后台）

- **FR-20.1 管理员管理**
  描述：超级管理员创建/编辑/停用管理员，分配一个或多个角色，重置密码。
  验收：admin 账号不可停用/删除；停用管理员的 token 立即失效（黑名单）。
- **FR-20.2 角色管理**
  描述：角色 CRUD，为角色勾选权限树（菜单 + 按钮）。
  验收：修改角色权限后，该角色下管理员刷新即生效（权限缓存按角色版本号失效）。
- **FR-20.3 权限（菜单）管理**
  描述：树形维护菜单/按钮/接口权限标识（如 `music:audit:pass`），前端按标识控制按钮显隐，后端按标识注解鉴权。
  验收：仅前端隐藏不算通过——无权限直接调接口必须返回 403。

### FR-21 系统设置与操作日志（后台）

- **FR-21.1 系统设置**
  描述：键值配置：站点名称、Logo、游客试听秒数、下载配额、模拟支付开关、MinIO 预签名有效期等，改后即时生效（Redis 缓存 + 更新时刷新）。
  验收：修改 `pay.mock` 后无需重启即切换支付方式。
- **FR-21.2 操作日志**
  描述：AOP 注解式记录后台写操作（操作人、模块、动作、请求参数摘要、IP、耗时、结果），支持检索。
  验收：审核、删改、权限变更等敏感操作 100% 有日志；日志查询不影响主流程（异步落库）。

## 4. 非功能需求

- **NFR-1 性能**
  - 播放量计数全部走 Redis（INCR/ZINCRBY），定时批量回写 MySQL，播放地址接口 P95 < 300ms（不含 MinIO 传输）。
  - 排行榜、每日推荐、发现页楼层数据 Redis 缓存，命中时接口 P95 < 200ms。
  - 列表接口一律分页，单页上限 100 条。
- **NFR-2 安全**
  - 认证：JWT（HS256，密钥 ≥256bit 且不入库不进仓库，走环境变量），accessToken 2h / refreshToken 7d，登出与停用走 Redis 黑名单。
  - 授权：后台 RBAC 到按钮/接口粒度；门户接口区分 游客/登录/VIP 三档，权益校验在服务端。
  - 密码：BCrypt（strength 10），任何接口与日志不回显密码。
  - 其余：参数校验（jakarta validation）、MyBatis-Plus 预编译防注入、上传文件类型白名单 + 大小限制、预签名 URL 短有效期防盗链、CORS 白名单。
- **NFR-3 音频播放**
  - 必须支持 HTTP Range/206 断点与拖动（MinIO 预签名直连天然满足；如走后端代理必须自行实现）。
  - 支持 mp3/flac/wav；浏览器不支持的格式（个别 flac 场景）由前端提示。
- **NFR-4 可用性与可维护性**
  - 统一响应体与错误码（见 api.md）；全局异常处理器兜底，5xx 不泄漏堆栈。
  - 关键定时任务（播放量回写、榜单快照、订单关闭、版权到期）失败告警写入实时动态。
- **NFR-5 数据**
  - 业务删除一律逻辑删除；订单、日志类数据只增不改（状态字段除外）。
  - MySQL utf8mb4；金额用 `DECIMAL(10,2)`，禁止浮点。
- **NFR-6 兼容性**
  - 门户支持 Chrome/Edge/Firefox/Safari 最近两个大版本；1280px 以上桌面优先，1024px 可用。
  - 音频优先 mp3（全浏览器兼容）；flac 在不支持的浏览器上提示"请使用 Chrome/Edge 播放无损"。
- **NFR-7 部署与环境**
  - 开发环境 MinIO 使用仓库 `deploy/minio/docker-compose.yml` 一键启动（Windows 用 `start-minio.bat`），首启初始化 `music`、`image` 两个私有桶。
  - 配置分离：`application-dev.yml` / `application-prod.yml`；密钥类（JWT secret、MinIO AK/SK、支付宝私钥）一律走环境变量。
  - 后端单实例即可满足本期目标（并发 ≤ 500 在线播放，播放流量由 MinIO 直连承担，不经应用服务器）。

## 6. 关键业务流程

### 6.1 最小链路：上传→审核→列表→播放

1. 管理员登录后台 → 音乐管理"上传"：选择本机 `E:\yinyu-music\resource\static\music` 下音频 → 后端解析元数据、存 MinIO 临时 key → 填写歌名/歌手/分类提交 → 曲目状态 PENDING。
2. 审核员在审核工作台试听 → 通过（状态 ONLINE，记录审核人）或驳回（必填原因，状态 REJECTED）。
3. 门户"新歌速递"/搜索出现该曲 → 用户点播放 → 前端调 `GET /api/songs/{id}/url` → 后端权益校验 + 签发预签名 URL + Redis 埋点 → 浏览器 `<audio>` 直连 MinIO（Range/206 支持拖动）。
4. 定时任务每 5 分钟把 Redis 播放增量回写 `song.play_count`，每日 0 点写 `play_stat_daily` 快照。

### 6.2 支付流程（支付宝沙箱）

1. 用户选套餐 → `POST /api/orders` 创建 PENDING 订单（15 分钟有效）。
2. `POST /api/orders/{orderNo}/pay?channel=ALIPAY` → 后端调沙箱下单接口返回收银台 → 用户沙箱账号付款。
3. 支付宝异步 `notify` → 后端 RSA2 验签 → 幂等更新订单 PAID → 发放权益（`user_vip.expire_at` 累加 / 写 `user_song_purchase`）。
4. 前端轮询订单状态确认到账；`pay.mock=true` 时第 2-3 步由"模拟支付成功"按钮直接触发。

### 6.3 权限生效流程（RBAC）

1. 超级管理员建角色并勾选权限树 → 保存时角色权限缓存版本 +1。
2. 新建管理员并绑定角色 → 管理员登录返回 `permissions` + `menus`，前端渲染菜单与按钮显隐。
3. 每次后台请求经拦截器校验注解权限标识；角色权限被修改后，成员下一次请求即按新权限判定（缓存版本失配即重查）。

| 风险 | 影响 | 对策 |
| --- | --- | --- |

## 8. 术语表

| 术语 | 说明 |
| --- | --- |
| 上架 / ONLINE | 曲目审核通过且未被下架，门户可见可播 |
| 待审核 / PENDING | 已上传未审核，仅后台可见可试听 |
| 预签名 URL | 后端用 MinIO SDK 签发的限时直连地址，播放与下载的唯一出口 |
| 埋点计数 | 播放地址接口内完成的 Redis INCR/ZINCRBY，非前端另行上报 |
| 内置歌单 | 每个用户的"我喜欢的音乐"，随注册创建，不可删改名 |
| 权益拦截 | 服务端在签发播放/下载地址前做的 VIP/已购/试听校验 |
| 权限标识 | 形如 `music:audit:pass` 的字符串，前端控按钮显隐、后端注解鉴权共用 |
| 双体系账号 | 门户 user 与后台 admin 两套表、两套登录、两套 JWT，互不通用 |
| 回写任务 | 每 5 分钟将 Redis 播放增量批量累加到 MySQL 的定时任务 |
| Rotation | refreshToken 一次一换，旧 token 立即作废的刷新策略 |
| Hi-Res 专区 | 无损（flac/wav）曲目聚合入口，VIP 专享完整播放 |
| 模拟支付 | `pay.mock=true` 时跳过支付宝、直接触发支付成功回调的开发/演示模式 |
